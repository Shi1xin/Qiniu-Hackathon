# Unit Tests

This directory contains unit tests for the Voice Assistant application.

## Test Organization

- `SpeechRecognitionTests.swift` - Tests for speech recognition service
- `CommandExecutionTests.swift` - Tests for command execution service
- `PreferenceTests.swift` - Tests for user preferences

## Running Tests

```bash
cd VoiceAssistant
swift test --filter UnitTests
```

## Test Coverage

Unit tests cover individual components and services in isolation.
